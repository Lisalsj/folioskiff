# Support

## Before requesting help

Read [README.md](README.md), the [documentation index](docs/README.md), and existing issues. Confirm the problem occurs on Windows 11 x64 with the current supported release and remove credentials or private research material from logs.

## Where to ask

- Use the bug-report issue form for reproducible defects.
- Use the feature-request form for product proposals and connector requests.
- Use the documentation label for unclear setup or configuration guidance.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities or accidental secret exposure.

This personal open-source project provides best-effort community support without response-time guarantees. It does not provide paid-paper access, publisher account support, legal advice, or recovery of third-party API credentials.

## Diagnostic information

Include the application version, Windows version, installation type, exact steps, expected and observed behavior, and a minimal redacted log. Never attach private PDFs, full prompts, backups, cookies, API keys, or personal reading history.
