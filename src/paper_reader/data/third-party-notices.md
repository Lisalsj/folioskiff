# FolioSkiff third-party notices

The Windows distribution includes open-source Python and JavaScript runtime dependencies.
Each release ships CycloneDX SBOM files containing the exact versions, dependency graph, package
URLs, and declared licenses for the bytes in that release.

The optional `intfloat/multilingual-e5-small` model is MIT licensed. RapidOCR is Apache-2.0
licensed; the optional PP-OCR model copyright is held by Baidu and the pinned ONNX conversions are
hosted by RapidAI. Model files are not part of the base distribution and are downloaded only after
the user reviews their purpose, size, source, and license.

This notice is informational and does not replace the license texts supplied by each dependency.
