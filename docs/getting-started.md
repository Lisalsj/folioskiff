# 开始使用页舟 · FolioSkiff

本指南面向 Windows 11 x64 的个人研究者。安装器和便携包均包含运行环境，无需安装 Python 或 Node.js。请从 [FolioSkiff 发布页](https://github.com/Lisalsj/folioskiff/releases) 下载 Windows 版本，并用同页的 SHA-256 清单校验。原 3.x 用户需手动安装 3.2.0 一次，升级后会沿用已有论文库。

## 1. 选择安装方式

- **安装器**：适合长期使用。安装在当前用户范围，不要求管理员权限，创建启动入口，并保留应用数据供后续升级使用。
- **便携 ZIP**：适合放在自选目录或移动磁盘。先完整解压再运行，不要直接在压缩包预览窗口启动。便携程序目录和论文库目录应分开，升级时只替换程序目录。
- **从源码运行**：仅供开发。参见 [贡献指南](../CONTRIBUTING.md)；不要把开发数据库、PDF 或凭据放进 Git 工作区。

下载成品后，将文件的 SHA-256 与同版本摘要清单逐字核对。首版制品未做 Authenticode 签名，Windows 可能显示信誉提示；不要从第三方下载站获取安装包，也不要在摘要不一致时继续运行。

## 2. 首次启动

以后可以在“设置 → 关于 → 应用更新”点击“立即检查”查看新版本。启动应用和打开设置时只读取本地版本记录。

启动器只监听 `127.0.0.1` 的动态端口，然后打开默认浏览器。URL 中的一次性启动秘密会立刻换成严格的本地会话 Cookie，并从地址栏移除。若浏览器没有打开，可从启动窗口复制本次本地地址；不要把该地址或诊断信息发送到公开 issue。

首次配置分四步：**存储与隐私 → Agent → 论文来源 → 阅读偏好**。只有存储与隐私是启动所必需的；Agent、付费来源密钥和偏好都可以跳过，稍后在设置中补充。详细说明见 [首次配置](first-run-setup.md)。

## 3. 最小可用流程

1. 在“关注计划”输入研究意图，例如“寻找医学影像中可解释扩散模型的新工作”。
2. 检查 Agent 或本地回退生成的中英文概念组，增删同义词、增强词和排除词，然后确认关键词版本。
3. 选择起止月份和来源，先看数量预估与样例，再运行计划。arXiv、OpenReview 与 Europe PMC 不配置商业 API key 也可使用。
4. 在阅读简报中打开论文；收藏、打开 PDF 或点击分析时才会按需获取全文。付费墙论文需要导入你合法取得的 PDF。
5. 在阅读工作台选中文字后使用统一论文 Assistant 进行提问、解释、翻译或生成相关推荐。正式分析报告仍需单独点击“分析”并通过预检。

## 4. 离线与降级

没有模型、API key、向量扩展或网络时，应用仍能启动和管理本地论文。关键词可手工维护；语义检索会降级为词法检索并降低置信度；缺少 IEEE Xplore、Springer Nature 或 OpenAlex key 时，对应能力显示为未配置而不是伪装成其他来源。OCR 和嵌入模型均在用户确认用途、体积与许可证后按需下载。

遇到启动、来源或 Agent 问题，请先看 [故障排查](troubleshooting.md)。AI 使用边界见 [论文 AI 阅读助手](ai-reading-assistant.md)，安全边界见 [v2 威胁模型](threat-model-v2.md)。
