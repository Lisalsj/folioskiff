# paper-reader v2 威胁模型

本模型描述本地单用户 Windows 11 x64 应用的已知信任边界、主要攻击路径、控制措施和剩余风险。它不是“永远无漏洞”的承诺；发布门槛是审计时没有已知未处置的阻断漏洞，并把无法在首版消除的限制如实记录。

## 资产与信任边界

受保护资产包括论文与标注、偏好和阅读历史、Agent 对话与报告、API 凭据、本地会话、备份以及发布白名单。主服务只监听回环地址；浏览器 SPA、主进程、插件子进程、Agent 后端、论文来源、外部网站和用户导入的文件位于不同信任域。PDF、网页、来源元数据和模型输出一律是不可信输入。

## 主要威胁与控制

| 威胁 | 控制 | 剩余风险 |
|---|---|---|
| PDF 提示注入诱导 Agent 泄露文件、联网或修改状态 | 论文文本只作为引用证据；系统指令与证据分隔；只读隔离工作目录；工具和网络按任务白名单；Agent 不能改评分、偏好和正式报告 | 模型仍可能生成错误或受文本影响的解释，用户必须核对页码证据 |
| SSRF、恶意重定向或私网探测 | URL 规范化；仅允许声明的 `https` 来源；DNS/重定向后再次检查目标；拒绝 loopback、链路本地、私网和文件协议；外部研究逐次显式同意 | 合法公开站点可能在请求后改变内容，引用保留访问时间但不能保证永久可复现 |
| 回环服务被其他网页调用 | 一次性 bootstrap secret 换取 HttpOnly、SameSite=Strict Cookie；移除 URL 临时信息；校验 Origin、CSRF、会话过期和 SSE 恢复序列 | 已控制本机账户或浏览器配置的攻击者仍可能访问用户会话 |
| 凭据进入数据库、日志、备份或 Git | 系统凭据库存储；日志脱敏；备份和发布白名单明确排除；诊断只导出安全字段；秘密扫描作为质量门槛 | 操作系统账户被攻破或用户主动粘贴 key 到笔记时无法由应用完全阻止 |
| 恶意或失控插件访问文件、网络和主进程 | Python entry point 只发现；插件在隔离子进程中以逐行 JSON 通信；默认无文件、网络和凭据权限；能力声明、deadline、协议校验与单插件熔断 | Windows 用户级进程隔离不是虚拟机级安全边界，只安装可信插件 |
| 路径穿越、压缩包逃逸、内容替换 | 解析并验证目标位于授权根目录；内容寻址 SHA-256；下载、模型和发行物校验哈希；解压拒绝绝对路径与父目录跳转 | 已有合法目录中的文件仍可能被同一账户下的其他进程替换 |
| 误发布私人研究数据 | 只从用户勾选内容生成 `PublishedSnapshot`；发布预览与隐私白名单；个性化文件不得进入 `main` | 用户主动选择的报告可能包含敏感观点，发布前仍需人工复核 |

## 网络策略

普通提问、解释和翻译固定为 `local_only`，不因论文内文字改变。官方论文来源检索只发送已确认关键词和来源要求字段。访问一般知识网站属于 `external_research`，每次任务都展示范围并要求显式同意。Ollama Local 只使用本机回环 API；Codex CLI 与 Ollama Cloud 明确标注为可使用云端的后端。

## 验证与响应

自动测试覆盖回环绑定、bootstrap 交换、Origin/CSRF、路径穿越、SSRF、日志脱敏、秘密泄漏、插件越权、PDF 提示注入和发布白名单。依赖审计、静态扫描、前后端测试与 source-free Windows smoke 共同构成发布证据。发现疑似漏洞时停止发布，不在公开 issue 披露复现细节，按 [SECURITY.md](../SECURITY.md) 私下报告；修复后补回归测试和审计记录。
