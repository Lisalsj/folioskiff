# v0.2 Discovery TDD 计划

## 目标

交付研究意图、不可变关键词、月份计划、来源预览、五个官方连接器、跨来源 Work 身份和可恢复运行。

## 任务

1. [x] **身份模型**：先测试 Work/SourceRecord/DocumentVersion 唯一约束、provenance 与模糊合并审阅，再实现迁移、Repository 和身份服务。
2. [x] **关键词版本**：先测试概念组 OR、必需组 AND、增强/排除、父版本差异、未确认禁止运行，再实现 schema、编译器和工作台 API。
3. [x] **Agent 与回退建议**：用固定输入测试双语 12–24 个起步词、继续扩展、无模型语料回退和完全手工模式；实现适配接口，不接评分。
4. [x] **日期与计划**：测试固定月份、滚动 N 月、时区、最近更新日期、>24 月警告、频率与错过待补跑；实现 DiscoveryPlan 快照。
5. [x] **来源预览**：测试估量、5–10 样例、关键词影响、缺 key 与能力差异；实现不污染正式库的 preview service。
6. [x] **arXiv/OpenReview/Europe PMC**：每个来源先加官方 fixture 契约、分页、日期、限流和异常测试，再实现连接器。
7. [x] **IEEE/Springer Nature**：先用官方响应 fixture 和无 key 禁用测试，再实现 key 配置、只读 live smoke 指南。
8. [x] **运行编排**：测试月份×来源批次、检查点、部分成功、重启恢复、取消和幂等；实现 PlanRun/RunBatch Job。
9. [x] **去重与代表版本**：测试 DOI、来源 ID、题名作者阈值、低置信度审阅、合法最新完整代表版本；实现人工审阅 UI。
10. [x] **端到端**：首次输入中文意图 → 修改/确认关键词 → 月份来源 → 预览 → 保存并运行；部分来源失败与重启续跑由后端故障注入测试覆盖。

每个任务完成后运行相关单元/契约测试、同步连接器文档并提交 `feat(discovery): ...`。禁止通过真实网络替代 fixture 测试。

## 退出条件

五来源能力矩阵真实可见；无 key/无模型仍能手工关键词并运行免费来源；未确认关键词绝不查询；部分失败可恢复；同一论文只显示一个 Work。
