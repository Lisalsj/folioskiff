# v0.3 Recommendation TDD 计划

## 目标

交付可降级检索、可解释四分制、版本化质量规则、元数据增强和受限偏好学习。

## 任务

1. ✅ 用中英金样测试 FTS5 tokenizer、字段权重、BM25 稳定排序，再实现索引与增量更新。
2. ✅ 测试 E5 下载清单、哈希、ONNX 推理、sqlite-vec 检测和词法降级，再实现向量服务。
3. ✅ 用固定金样测试相关性 40/40/20、缺维度重归一和 coverage/confidence 降级。
   - ✅ 将运行冻结关键词、`RunCandidate`、FTS5 与可选 E5 汇合为候选范围严格受限的相关性结果；原生语义异常整批降级。
4. ✅ 为 OpenAlex、S2、Crossref 先写字段 provenance、认证、限流和 fixture 契约，再实现 enrichers。
   - ✅ 三个官方单篇接口、稳定 ID 匹配、禁用/不适用/404/限流语义、规范字段与逐字段 provenance 已由 fixture 契约覆盖。
   - ✅ `0009_metadata_observations` 保存只追加观察历史、重试幂等、最新读取和 Work 合并迁移/去重。
   - ✅ OpenAlex/Semantic Scholar/Crossref 的逐项 Windows 凭据设置、环境回退、能力 API 和设置页已完成且永不回显值。
   - ✅ 运行级持久 Job 冻结候选/增强器版本，逐项 checkpoint、部分成功、取消、启动恢复、显式失败重试和最新证据 API 已完成。
5. ✅ 测试质量七维权重、中性先验、未知与不适用、规则版本，再实现 ScoreSnapshot。
   - ✅ `quality-v1` 保留每维观测值/中性填充值、证据与有效权重；`0010_score_snapshots` 以内容哈希幂等保存并由数据库触发器保证不可变。
6. ✅ 测试 CCF 2022 适用性和 CSV/XLSX 导入验证；实现 JCR/CAS/新锐独立证据，拒绝混合伪造。
   - ✅ 内置 CCF 2022 第六版的 2024 官方更名修订，完整保存 649 条场所、旧名、页码、来源 URL 与 PDF 哈希；歧义简称不猜测。
   - ✅ `0011_rating_catalogs`、合法使用确认、CSV/XLSX 验证、不可变内容/可变活动指针、34/33/33 缺失降置信语义、管理 API 与设置页已完成。
7. ✅ 测试撤稿硬排除、关注声明/重大更正警告、代码/模型必须明确关联，再实现危险规则。
   - ✅ `integrity-v1` 将撤稿/来源冲突设为可见但默认不可推荐的硬约束，关注声明/重大更正/恢复声明形成不可抵消的强警告与置信度上限，并冻结进 ScoreSnapshot。
   - ✅ `artifact-impact-v1` 只允许精确匹配明确论文关系的 GitHub/Hugging Face 指标；Crossref 自动关系受论文主体、关系类型、URI 和规范资源地址四重约束，Agent/相似名称不能解锁热度。
8. ✅ 测试 40/40/10/10、历史月份重分配、五种排序和 80/20 探索配额，再实现推荐器。
   - ✅ `composite-v1` 保留四信号分数/覆盖度/置信度；固定历史月份使用 45/45/0/10，完整性置信度上限与默认资格在综合结果中继续生效。
   - ✅ 综合/相关性/质量/最新/偏好五视图具有固定 tie-break；默认 20/最多 50 的 80/20 选择器优先覆盖三类可解释探索原因，不足时显式降级并用利用项回填。
9. ✅ 测试显式反馈、隐式事件白名单、180 天聚合、历史匹配和不喜欢抑制，再实现偏好服务。
   - ✅ `0012_preferences`、独立库状态、兴趣作者、六类事件白名单、服务端事件时间、幂等键、严格保留边界和不可逆聚合已经完成；Work 合并会保守合并状态并迁移事件/权重。
   - ✅ `preference-v1` 使用中性先验与有上限的显式/作者/行为增益；不喜欢是默认抑制硬规则，已读/收藏/已分析论文独立列为历史匹配且不占新论文配额。
   - ✅ `/api/v1/library` 提供受会话/Origin/CSRF 保护的状态、作者、事件和解释分 API；浏览器不能提交原始事件时间或白名单外行为。
10. ✅ 构建分数证据面板、规则编辑器与端到端解释一致性测试。
    - ✅ `0013_score_rules` 保存不可变公式修订和活动指针；七维启用/停用、权重总和、未知因子和历史不可篡改均有数据库/领域金样。
    - ✅ 质量评分与 ScoreSnapshot 使用活动规则的真实权重和版本；冻结快照读取 API 原样返回组件、缺失策略、硬约束与内容哈希，界面不二次计算。
    - ✅ 设置页以“安静图书馆”双栏呈现规则编辑和证据预览，桌面/移动 Playwright、axe、Vitest、TypeScript 与生产构建通过。

每步先保存失败金样，再做最小公式实现；所有浮点边界、tie-break 和版本号必须固定。提交使用 `feat(recommendation): ...`。

## 退出条件

缺引用/榜单不会被判低质量；每个分数可追溯到证据与规则；向量不可用仍可推荐且明确降级；Agent 无评分写权限。
