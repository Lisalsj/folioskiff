# v0.9 产品闭环实施计划

> **执行要求：** 使用 `superpowers:executing-plans` 按顺序执行。每个任务都必须先写并运行失败测试；不使用子代理。

**目标：** 把现有独立领域组件连接成“来源修订 → 推荐评分 → 阅读简报/结果 → 用户反馈 → 按需分析”的持久、可恢复、可解释用户闭环。

**关键边界：** 研究意图只生成关键词建议；只有已确认关键词参与筛选。Agent 不参与评分。重要修订进入更新区且不占新论文配额。缺失质量证据是中性 50 分并降低覆盖度/置信度，不是低质量。

## 完成定义

- 真实用户可以从计划运行进入持久推荐结果，并在首页看到后续简报。
- 新论文、历史匹配、重要修订和纯元数据刷新被明确分流；更新不占新论文配额。
- 每篇论文独立显示 relevance/quality/confidence/coverage 和证据，缺失不被打低分。
- 反馈可操作、可恢复、可解释，且不会被 Agent 修改。
- 三种视口、时区和主题完成自动化验收；文档与真实能力一致。
