# 首次配置

paper-reader 的首次配置是四步向导：**存储与隐私、Agent、论文来源、阅读偏好**。向导会保存每一步的完成状态；除“存储与隐私”外都可以跳过。跳过只会让对应能力清晰降级，不会阻止进入本地论文库，也不会在后台偷偷下载模型或测试云端服务。

## 1. 存储与隐私

只选择一个数据根目录，默认是 `Documents\paper-reader`。应用自动派生 `state`、`cache`、`library` 和 `library\backups`，并展示每个目录的用途。向导会检查根目录是否为绝对路径、可写、未通过符号链接越界，并在迁移时写入可恢复 journal。迁移完成并重启健康检查成功后，旧目录只保留不含敏感数据的启动重定向配置。

默认是单机、单用户、零遥测。论文内容、阅读行为、标注和报告不会自动发布；原始隐式阅读事件保留 180 天后只留下不可逆聚合。不受保护且标记“不喜欢”的全文缓存默认 90 天后只删除文件，元数据与反馈仍保留。

## 2. Agent

可以选择 Codex CLI、Ollama Local 或 Ollama Cloud，也可以暂时不配置。向导只做能力探测，不自动生成报告。Codex 复用自身登录状态，paper-reader 不复制凭据、不修改 `~/.codex/config.toml`；Ollama Cloud 的 key 进入操作系统凭据库。后端、模型、推理强度和联网范围在每次分析预检中仍可覆盖。详见 [Codex 与 Ollama 配置](codex-ollama-setup.md)。

## 3. 论文来源

先启用无需商业密钥的 arXiv、OpenReview 和 Europe PMC。IEEE Xplore、Springer Nature、OpenAlex 等需要官方凭据时，界面会提供申请入口和只读连通性检查；缺少 key 的来源保持“未配置”，不会由聚合器冒充。每个来源都显示日期语义、限流状态和特有过滤器。

## 4. 阅读偏好

可填写研究领域、关注作者、默认报告语言、默认英译中目标和探索比例。阅读偏好只影响个性化排序与建议，不覆盖客观质量、相关性、置信度或数据覆盖度。以后可以在设置中查看、编辑或清除偏好；Agent 永远不能替用户修改评分和反馈。

## 完成、返回与重置

完成页会列出已启用能力和降级项，确认后才进入阅读简报。中断向导后再次启动会回到最后一个安全检查点。

“设置 → 数据与隐私 → **重置本地数据**”会先展示将删除的数据库、缓存、索引、模型与日志，并要求用户明确确认；受操作系统凭据库管理的密钥单独清除。建议先生成手动备份，但备份本身不包含凭据。重置后服务安全退出，再次启动会重新进入四步首次配置。不要通过删除 Git 仓库或随意清空 `%LOCALAPPDATA%` 代替产品内重置流程。
