# v1 隐私数据流与无障碍审计

更新日期：2026-07-16

本文记录 `paper-reader` v1.0 的隐私数据流和 WCAG 2.2 代码级审计。自动化结果只能证明被覆盖的行为；它不替代 Windows 11 干净环境中的 NVDA/Narrator、键盘、浏览器缩放和 Windows 高对比度人工验收，因此本文不能单独证明这些人工场景已经通过。

## 1. 审计结论

隐私边界采用关闭式数据流：默认数据只在本机；便携备份明确包含完整 SQLite 状态和数据库引用的合法 PDF；Agent 只在用户确认关键词或点击分析、聊天、比较后取得当前任务所需证据；精选发布只读取逐列白名单。凭据、任意本机路径和未选私有内容不存在从数据库到公开快照的通路。

本轮关闭了六个可验证缺口：主壳层缺少跳过重复导航入口、SPA 路由切换后焦点留在旧页面、文档标题不随路由变化、备份界面没有充分披露 SQLite 内的私密内容及未加密导出的风险、归档清单描述过于笼统，以及阅读器手写标签没有方向键/单一 Tab 停靠点。三种视口下的键盘、目标尺寸、200% 文本重排、强制颜色、降低动画和 axe 聚焦验收均已通过。

## 2. 隐私数据流矩阵

“进入备份”表示该数据位于完整 SQLite 快照或是数据库当前引用的合法 PDF。未加密便携包可被取得该文件的人读取；启用密码时使用流式 AES-256-GCM。凭据、日志、模型、缓存、临时文件和旧备份不进入便携包。

| 数据类别 | 本地保存与保留 | 便携备份 | Agent 可见范围 | 精选发布 | 日志、诊断与删除 |
|---|---|---|---|---|---|
| Work、来源记录、研究计划、关键词版本 | SQLite；关键词确认版本不可变 | 进入 | 关键词任务接收研究意图与用户确认的偏好缩减上下文；论文任务接收所选 Work 的必要元数据 | 只允许用户选择的规范题名、作者、摘要、DOI、日期 | 错误不回显原始来源响应或本机路径 |
| PDF 原始字节 | 内容寻址对象库；只在打开、收藏或分析时按需取得 | 数据库当前引用且合法可读的对象进入 | 不直接发送整份 PDF；只有文本指向关键图表且后端支持视觉时，才发送最多 6 个受限页图 | 禁止 | 未受保护且明确不喜欢的全文在 90 天后仅经预览和显式应用清理；收藏、置顶、报告或批注保护文件 |
| 原生提取文本与 OCR 全文 | 页级 SQLite 证据，绑定文档 SHA-256、页码和引擎版本 | 进入 | 仅当前分析、聊天或比较任务的冻结证据进入所选后端 | 禁止 | 原生/OCR 失败只保留稳定分类；不把解析器异常写入用户界面 |
| 阅读位置、批注、书签与私有笔记 | SQLite；批注绑定不可变内容哈希 | 进入 | 当前所选文档的批注可进入论文分析、聊天和比较证据；阅读位置不进入模型提示词 | 禁止 | 有批注的全文不能自动清理；版本迁移必须逐条确认 |
| 相关性、质量与客观评分证据 | SQLite 不可变快照，含规则、权重、缺失策略和来源 | 进入 | Agent 不参与评分、排序或反馈，也无评分写接口 | 只可公开最新客观质量分、覆盖度、置信度、规则版本和快照哈希；组件、权重和原始证据禁止 | 缺失证据使用中性先验并降低覆盖度，不能记录成低质量 |
| 正式报告、完整提示词与失败草稿 | 正式报告不可变；失败草稿只含脱敏诊断 | 进入 | 完整组合提示词与冻结证据只在用户点击分析后发送给所选后端 | 只有用户明确选择的正式报告正文可公开；完整提示词、证据清单、失败草稿、模型诊断和未选报告禁止 | 诊断统一脱敏；失败不能覆盖既有正式报告 |
| 论文聊天与压缩检查点 | 每个 Work 一个持久会话；原始消息不删除，检查点只追加 | 进入 | 当前会话的受限上下文、原始问题与论文证据进入用户选择的后端 | 禁止 | 流式片段先持久化再发送；失败不改变报告或评分 |
| 显式收藏、喜欢/不喜欢原因、关注作者 | SQLite | 进入 | 只通过可见的偏好缩减上下文影响关键词建议和个性化；反馈原因不直接发送 | 禁止 | 不记录键盘、鼠标或系统浏览行为 |
| 原始隐式事件 | 只允许列表、详情、PDF 打开、四档阅读时长、完成阅读和生成报告 | 在 180 天窗口内进入 | 不直接发送；关键词上下文不查询原始事件表 | 禁止 | 严格保留 180 天，过期后按 Work 求和并删除原始行 |
| 不可逆偏好聚合权重 | SQLite，只保留 Work 总权重与聚合边界 | 进入 | 可作为用户可见偏好缩减上下文和本地个性化证据 | 禁止 | 无法还原原事件类型、时间或操作序列 |
| 来源、增强器、Ollama Cloud 凭据与 Codex 登录 | Windows Credential Manager 或 Codex 自有登录状态；SQLite 只保存引用/配置状态 | 禁止 | 仅交给被授权的具体连接器或后端；Codex 凭据不由应用读取、复制或改写 | 禁止 | 日志、Job、SSE、诊断包和错误响应均不得包含值 |
| 模型、向量缓存、下载临时文件与日志 | `%LOCALAPPDATA%\paper-reader` 的独立根 | 禁止 | 本地模型只从本机证据执行；模型下载不携带论文或偏好 | 禁止 | 使用独立清理策略；日志在最终 formatter 后再次脱敏 |
| PublishedSnapshot 与公开站点字节 | SQLite 中不可变冻结快照及固定四文件清单 | 进入 | 不作为新的 Agent 输入 | 仅发布快照自身的白名单字节到 `published` | 发布失败保留旧成功快照；重试复用相同冻结字节 |

## 3. Agent 出站授权

关键词建议、单篇报告、论文聊天和多篇比较是四种独立命令。研究意图不会直接筛选论文；只有用户确认的不可变关键词版本能触发检索。分析、聊天和比较在用户操作前保持零模型调用。

Ollama Local 只访问固定本机 API。Codex CLI 与 Ollama Cloud 可能把所选证据交给云端，因此预检必须持续展示后端、模型、推理强度、语言、证据等级、提示词模板和联网开关。外部网络研究默认关闭；开启后外部判断必须有独立 HTTPS 引用。论文正文中的提示注入不能修改模型、推理、service tier、sandbox、MCP/工具或联网参数。

## 4. 无障碍验收矩阵

基准采用 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)。重复导航的跳过机制对应 [2.4.1 Bypass Blocks](https://www.w3.org/WAI/WCAG22/Understanding/bypass-blocks.html)，逻辑焦点对应 [2.4.3 Focus Order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)，固定层不得遮住焦点对应 [2.4.11 Focus Not Obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)，最小指针目标对应 [2.5.8 Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。

| 表面 | 必须成立的行为 | 当前自动化证据 | 仍需人工复验 |
|---|---|---|---|
| 应用主壳层 | 首次 Tab 显示“跳到主要内容”；Enter 聚焦唯一 `main`；路由切换后焦点进入新主内容；当前导航有 `aria-current` | `AppShell.spec.ts`、`foundation.spec.ts` | NVDA/Narrator 是否以自然中文宣告新页面 |
| 页面标题与结构 | 每个稳定路由有描述性中文标题；页面有唯一主要区域和清晰 H1 | `App.spec.ts`、三视口 Playwright | 浏览器后退/前进与深链接的语音上下文 |
| 主导航 | 1440×900、900×900、Pixel 7 均保持 6 个可命名入口；每个目标至少 24×24 CSS px | `foundation.spec.ts` 运行时尺寸断言 | Windows 触控、放大镜和语音控制 |
| Dialog 与抽屉 | 打开后焦点进入，Escape 关闭并返回触发器；隐藏抽屉使用 `aria-hidden` 与 `inert` | reader、plugins、model-assets、analysis、backup E2E | 全流程 Shift+Tab、嵌套对话框和系统输入法 |
| 阅读器面板切换 | 桌面 Agent 使用 Reka UI Tabs 自动方向键激活；移动 PDF/批注/报告/聊天使用 Reka UI 单选切换组和 roving focus；切换不卸载 PDF 或已访问的报告/聊天 | `ReaderWorkspacePage.spec.ts` 与三视口 `reader.spec.ts` | NVDA/Narrator 对标签、切换按钮和面板关系的自然中文宣告 |
| PDF 阅读器 | PDF 页面不随深色主题反色；有页级可访问名称、文本层、搜索和键盘快捷键 | `reader.spec.ts` 的真实 PDF.js、白色画布、文本层、刷新恢复与 axe | NVDA 对文本层阅读顺序；扫描 PDF 的 OCR 朗读质量 |
| 移动阅读 | PDF、批注、报告、聊天切换不卸载 PDF，会保留页码、缩放、旋转和阅读位置 | Pixel 7 完整 reader E2E | 实机触控与软键盘遮挡 |
| 文本重排 | 200% 根字号不产生页面级水平滚动；320 CSS px 起可用 | foundation、backup、recommendation、model-assets、plugins、updates E2E | 浏览器 400% 页面缩放和 Windows 文本缩放 |
| 颜色与动画 | 浅色、深色、跟随系统、Windows 强制色和降低动画下状态不只依赖颜色 | axe、forced colors、`prefers-reduced-motion` 测试与 CSS 门禁 | Windows 高对比度主题逐屏视觉复核 |
| 动态任务与错误 | 进度使用 `progress`/`aria-live`；错误使用稳定可恢复文案；私有诊断不进入 DOM | jobs、backup、analysis、reader、models E2E | 长任务取消、离线恢复的实际屏幕阅读器宣告频率 |
