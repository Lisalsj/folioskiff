# ADR-0003：Agent 与评分系统严格隔离

- 状态：已接受
- 日期：2026-07-13

## 背景

语言模型适合建议关键词、解释论文和综合证据，但输出不稳定、依赖提示词且可能受正文提示注入影响。若模型直接决定质量分或排序，结果不可复现且难以解释。

## 决定

评分由确定性版本化规则、公开证据和用户偏好事件计算。Agent 只能读取允许的分数与证据用于解释，不得写 ScoreSnapshot、LibraryState、排序或反馈。报告和聊天独立版本化，模型失败不影响推荐状态。

## 后果

推荐可审计、可回归测试，模型可自由切换；用户可能看到 Agent 判断与质量分不同，界面必须清楚解释二者目的不同。
