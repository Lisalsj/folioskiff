# ADR-0001：采用本地模块化单体

- 状态：已接受
- 日期：2026-07-13

## 背景

v1.0 是 Windows 单机单用户产品，需要免运行时安装、离线降级、低维护成本和强本地隐私。Electron、Redis、Celery 或独立数据库会增加体积、端口、更新与故障面。

## 决定

使用单个 Python 进程：FastAPI 同时提供 Vue SPA 与 `/api/v1`，SQLite/WAL 保存状态，持久 Job 执行长任务。CPU/不可信任务可以使用受控子进程，但不成为常驻外部服务。

## 后果

部署和备份简单，事务边界清晰；同时必须避免事件循环阻塞，并为抓取、OCR、模型和插件设计取消、检查点、资源上限与子进程隔离。未来团队/远程产品需要新的 ADR，不能在此架构上偷偷加入多用户假设。
