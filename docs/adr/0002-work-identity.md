# ADR-0002：Work 作为稳定论文身份

- 状态：已接受
- 日期：2026-07-13

## 背景

同一研究成果可能同时存在预印本、会议、期刊、来源镜像和多个文件版本。直接以 arXiv ID、DOI 或 PDF 作为主键会造成重复反馈、报告错绑和版本覆盖。

## 决定

`Work` 表示规范研究成果，`SourceRecord` 表示来源事实，`DocumentVersion` 表示具体内容。DOI、来源 ID、题名-作者相似度按置信度生成合并建议；低置信度只能人工确认。报告与标注绑定内容哈希，不只绑定 Work。

## 后果

跨来源列表可稳定聚合，旧报告可复现；代价是需要 provenance、代表版本选择和人工去重队列。任何导入路径都必须经过同一身份服务。
