# v2 隐私数据流与无障碍审计

更新日期：2026-08-01

本文记录 v2 发行候选前的代码级隐私、键盘、响应式和 WCAG 2.2 自动化证据。测试环境为 Windows 11 Pro build 26200、Chromium 149.0.7827.55；视口为桌面 `1440×900`、中等 `900×900` 与 Pixel 7。自动化与 Agent 审阅不能替代独立用户使用 NVDA/Narrator、实机触控、Windows 高对比度和干净虚拟机的人工验收，未执行项在末尾明确保留。

## 1. 结论

首次配置、统一论文 Assistant、英译中和相关推荐没有引入隐式模型调用或默认外部研究。普通提问、解释和翻译冻结为 `local_only`；访问一般知识网站必须在当前相关推荐任务显式同意。凭据仍只由操作系统凭据库或 Codex 自身拥有，数据重置与精选发布都使用预览、白名单和二次确认。

本地自动化收据为：Python `1,635 passed / 15 skipped / 0 failed`，总体覆盖率 `85.04%`，核心领域分支 `93.59% (365/390)`；Vitest `96 files / 242 tests`；Playwright `112 passed / 8 skipped / 0 failed`。8 个跳过项只是在中等与移动项目关闭桌面硬件性能测试，不跳过用户旅程、axe、键盘或视觉检查。所有已执行 axe 扫描为零自动发现违规，24 张三视口视觉基线通过。

## 2. v2 隐私数据流

| 能力 | 本地事实 | 可能离开本机的内容 | 用户控制与禁止项 |
|---|---|---|---|
| 四步首次配置 | `onboarding_state`、非敏感运行配置、来源/Agent 能力状态 | 只读 Agent/来源探测可能访问用户明确配置的服务 | 存储与隐私必填；其他步骤可跳过；探测不生成文本，不回显 key |
| Assistant 提问/解释 | Work 会话、冻结证据快照、消息、片段、检查点 | 仅发送当前选区/页/文档证据给所选后端 | 点击发送才调用；固定 `local_only`；正文不能改工具、网络或评分 |
| 英文到简体中文 | 版本化 artifact、segment、glossary 与导出哈希 | 所选文本和术语可交给用户选择的 Agent 后端 | 不访问外部网站；源文档哈希变化后旧翻译标为过期；导出不含凭据 |
| 相关推荐论文 | 可编辑检索意图、确认版本、来源批次、候选与出处 | 确认后向已启用学术来源发送检索条件 | Agent 草稿不能自动搜索；只保存经验证论文；部分失败可恢复 |
| 相关知识网站 | URL、访问时间、验证状态和证据摘要 | 仅当本次任务 `external_research` 获得显式同意 | SSRF/DNS 重绑定/重定向复验；只允许验证后的公开 HTTPS；不发送私有 PDF |
| 重置本地数据 | 预览、一次性确认、迁移前快照与重启请求 | 不产生外部请求 | 只处理授权根；拒绝 reparse point/根目录；凭据单独清除；备份不含凭据 |
| 日志与安全诊断包 | 版本、公开状态码、脱敏任务分类 | 只有用户手工导出后才可能发送 | 排除 PDF、数据库、聊天、报告、偏好、路径、Cookie、启动秘密和 key |

Agent、翻译、相关推荐与正式报告分别持久化，失败不能覆盖正式成果，也不能改写评分快照、排序和反馈。完整攻击路径见 [v2 威胁模型](threat-model-v2.md)。

## 3. 键盘与焦点检查清单

以下路径使用真实 Chromium 键盘事件逐步执行，并由断言与视觉基线共同审阅；这属于可复现的浏览器级检查，不冒充独立屏幕阅读器人工测试。

- [x] 首次 Tab 显示“跳到主要内容”，Enter 进入唯一 `main`；路由变化后标题与焦点同步。
- [x] 四步首次配置可仅用 Tab、Shift+Tab、Space/Enter 前进、跳过和完成，错误与能力降级可见。
- [x] 阅读器 PDF/Assistant/报告区域使用单一 Tab 停靠点与方向键切换，Escape 关闭抽屉并返回触发器。
- [x] Assistant 的提问、解释、翻译、相关推荐具有可读名称；选区、证据范围、网络策略和发送按钮顺序一致。
- [x] 外部研究同意、插件精确权限、备份恢复与数据重置的对话框会捕获焦点，拒绝路径不产生副作用。
- [x] 任务抽屉、进度、失败与重试使用 `aria-live`/`progress`，私有诊断不进入 DOM。

## 4. 视觉、颜色与重排证据

- 桌面、中等和 Pixel 7 的首页、首次配置、设置概览、论文库、阅读器、英译中与部分相关推荐共 24 张基线通过；PDF 页面在深色模式仍保持白色纸面。
- `prefers-reduced-motion: reduce` 覆盖主壳层、模型、备份、插件、阅读器、更新、主题与视觉基线，关键状态不依赖动画完成。
- `forced-colors: active` 覆盖主壳层、模型、插件、推荐和更新；焦点、选择、警告与禁用状态不只靠颜色区分。
- 200% 根字号和 320 CSS px 起的布局无页面级水平滚动；桌面三栏在 900 px 收为抽屉，Pixel 7 使用保留 PDF 阅读位置的标签切换。
- 阅读简报与阅读器实测 CLS 都为 `0`；初始 JavaScript 闭包为 `236,124 / 350,000` 字节，进入阅读简报前不请求 PDF.js worker。

## 5. 仍需独立人工复验

- [ ] NVDA 与 Narrator 的中文标题、标签关系、动态任务频率和 PDF 文本层阅读顺序。
- [ ] 浏览器 400% 页面缩放与 Windows 系统文本缩放，不以 200% 根字号自动化替代。
- [ ] Windows 高对比度主题逐屏视觉检查，不以 Chromium forced-colors 仿真替代。
- [ ] Pixel 7 或同级实机触控、软键盘遮挡、旋转与长 PDF 手势。
- [ ] Windows 11 x64、16 GB、普通 SSD、无 Python/Node/Git 干净环境的安装、升级、卸载和 source-free 生命周期。

这些限制不会被写成“已通过”。当前个人开源候选的代码级门禁无已知阻断问题；最终制品收据仍须绑定确切 manifest、哈希和可执行文件。整个审计没有 push、tag、GitHub Release 或 Actions 调用。

## 6. v2.0.0 制品与证据隐私复核

冻结的十文件发行集、1,052 个 portable 成员名、严格 clean-smoke JSON 与两份启动基准证据均已执行本地只读扫描：

- 工作区绝对路径的 Windows/正斜杠形式、Windows 用户名、`.codex` 和常见 key/token 形态均为 0 命中；
- portable 中 PDF、BibTeX、SQLite/DB 和凭据命名成员均为 0；发行清单本身不包含论文、作者、标注、聊天、报告、偏好、凭据或完整提示词；
- `CHANGELOG.md` 两处 `prompt` 只说明模板版本和提示注入隔离，经分类不属于提示词正文；
- onedir 内容验证器带当前工作区为禁止构建根执行，1,051 个文件逐字节扫描后通过；
- 启动证据最初暴露本地可执行文件绝对路径，新增回归测试并改为只输出 `paper-reader.exe` 后重新采集 20+20 样本；旧本地 JSON 同样已脱敏，所有证据复扫为 0 命中。

完整哈希、生命周期和未验证外部条件见 [v2.0.0 本地发行收据](v2-local-release-receipt.md)。这项本地扫描减少误发布风险，但不能替代公开制品发布后的第三方复核。
